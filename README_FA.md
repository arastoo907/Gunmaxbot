# گانمکس بات (GunMax Bot) — نسخه نمایشی 0.1.0

این پروژه سورس اولیه اپلیکیشن اندروید با Kotlin و Jetpack Compose است.

## ساخت APK فقط با گوشی (بدون کامپیوتر)

1. در گوشی وارد GitHub شوید و یک حساب بسازید یا وارد حساب خود شوید.
2. یک مخزن جدید (New repository) بسازید.
3. فایل ZIP این پروژه را از حالت فشرده خارج کنید و تمام محتویات پوشه را در مخزن بارگذاری کنید؛ پوشه `.github` را هم حتماً بارگذاری کنید.
4. در مخزن، بخش **Actions** را باز کنید.
5. گردش‌کار **Build GunMax Bot APK** را انتخاب کنید و **Run workflow** را بزنید.
6. پس از اتمام موفق ساخت، وارد اجرای (workflow run) سبزرنگ شوید.
7. در بخش **Artifacts** فایل `GunMaxBot-debug-apk` را دانلود و از ZIP خارج کنید.
8. فایل `app-debug.apk` را روی گوشی باز و نصب کنید. ممکن است اندروید اجازه نصب از همان برنامه دانلودکننده را بخواهد.

## وضعیت نسخه فعلی
- داشبورد فارسی راست‌به‌چپ و تم تیره
- کارت‌های آمار و نمایش سه اکانت نمونه
- کادر ورود دستور فارسی
- گزارش فعالیت نمایشی

## مهم
این نسخه فقط رابط کاربری آزمایشی است. دکمه‌ها و وضعیت‌ها نمایشی‌اند و هنوز به Minecraft/GunMax متصل نمی‌شوند. ورود اکانت، اجرای بات، اتصال ابری و اجرای مأموریت‌ها هنوز ساخته نشده‌اند. برای اتصال واقعی باید روش مجاز اتصال سرور و اجازه آن برای کلاینت خودکار بررسی شود. اطلاعات حساب Microsoft یا رمز عبور را در نسخه نمایشی وارد نکنید.
